# VoltTech V5 Clean Rebuild

This directory is an isolated visual/UX prototype.

## Rules
- No legacy VoltTech frontend CSS is imported.
- No production Supabase, Yoco, account, checkout or catalogue logic is connected.
- Existing brand/media assets may be referenced from the repository.
- Prototype pages are noindex/nofollow.
- Mobile-first review widths: 360px and 390px.
- Desktop review width: 1440px.

## Approval gate
Only these three screens exist initially:
1. Homepage
2. Store
3. PC Builder

The rest of the VoltTech website must not be rebuilt into V5 until this design direction is approved.
