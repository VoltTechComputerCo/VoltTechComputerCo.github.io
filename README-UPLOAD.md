# VoltTech V3 — Full Site Visual Rework

Branch: `v3-prototype`

This batch carries the approved V3 homepage/reference styling into the rest of the CUSTOMER-FACING website.

The design target is the approved homepage/reference language:
- dark graphite / black foundation
- VoltTech teal dividers and controls
- dense horizontal information architecture
- squared / technical panels instead of soft rounded SaaS cards
- compact mono labels
- strong image-led heroes
- tight spacing and store/configurator feel
- mobile layouts that remain touch-friendly

## Deliberately NOT changed

No JavaScript files were replaced.
No Supabase files were replaced.
No IDs or data attributes were changed.
No forms or backend requests were rewritten.
No routes were renamed.
No Store launch gate was removed.
No Builder launch gate was removed.
No PC-build availability claims were added.

STATIC keeps its separate editorial identity and is not overwritten by this batch.

Admin-only pages are also left alone for now; this batch is the customer-facing V3 conversion.
