NVIDIA Just Entered the Windows CPU War

The Surface Laptop Ultra pairs an NVIDIA Grace Arm CPU with Blackwell RTX graphics and up to 128GB of unified memory. It could reshape high-end Windows laptops, but gaming compatibility still matters.

Published 8 October 2026 · STATIC

NVIDIA is no longer just the company supplying the GPU inside someone else's Windows laptop. Microsoft's new Surface Laptop Ultra, announced on 7 October, is built around NVIDIA's RTX Spark Superchip: a Grace Arm CPU alongside Blackwell RTX graphics, sharing a unified memory pool.

Preorders opened at $2,599.99, with availability beginning 16 October. That entry price does not buy the headline 128GB memory configuration. Microsoft's store lists the starting model with an 18-core CPU, 5,120 GPU cores, 24GB unified memory and a 512GB SSD; the higher 20-core, 6,144-GPU-core tier starts at $3,699.99. The listed 128GB model reaches $5,899.99 in the US.

Confirmed: RTX Spark is an NVIDIA Arm-based Windows platform with Blackwell RTX graphics. Microsoft lists ray tracing, DLSS and NVIDIA Reflex in supported games. That is not a guarantee of universal x86 game or anti-cheat compatibility.

Why the CPU is the bigger story

NVIDIA has dominated discrete PC graphics for years. RTX Spark brings its own CPU architecture into premium Windows laptops, competing for the entire processor platform rather than only the GPU slot. The partnership also places Microsoft firmly behind Windows on Arm as a high-performance creative and local-AI platform.

For software developers, the 128GB unified-memory ceiling is striking. CPU and GPU workloads can draw from a shared pool instead of shuttling data between separate system and graphics memory. That is especially relevant to large local AI models and certain 3D or compute workflows, although usable memory and real-world speed depend on configuration and software.

Can it actually game?

Microsoft advertises ray tracing, DLSS and Reflex in supported titles, and NVIDIA is promoting Windows gaming on Arm. The crucial qualification is supported. Game launchers, anti-cheat drivers, legacy middleware and architecture-specific dependencies can complicate Arm compatibility even when the graphics hardware is capable.

Without independent game-by-game tests, performance and compatibility claims should remain provisional. A machine designed primarily for creators and local AI should not be treated as a proven substitute for a similarly priced x86 GeForce gaming laptop.

Unified memory changes the buying decision

The $2,599.99 starting configuration has 24GB of unified memory, not 128GB. Buyers considering large local AI models need to compare actual configuration prices, model quantization requirements, bandwidth, thermals and software support rather than treating the platform's maximum specification as standard.

Microsoft also introduced a Surface RTX Spark Dev Box for $5,999, due to ship in November, and announced RTX Spark systems from ASUS, Dell, HP, Lenovo and MSI. That broader ecosystem matters more than any single Surface product: NVIDIA is attempting to establish an entire category of Windows hardware.

STATIC's take

The interesting question is not whether NVIDIA can build an expensive Windows laptop. It is whether RTX Spark can make Windows on Arm credible for creators and gamers who previously depended on x86 compatibility and dedicated graphics. NVIDIA's graphics expertise and Microsoft's platform support make this the strongest challenge yet, but software and independent benchmarks will determine whether it succeeds.
