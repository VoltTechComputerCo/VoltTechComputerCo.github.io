# Store browsing

Category cards link directly to the category catalogue. GPU maker and brand controls are displayed as prominent buttons without staged dropdowns. A selected maker with no supplier products remains selected and shows an empty result.

The header cart remains visible on mobile. The store renders only the chosen page of cards (10 by default; 25, 50 and 100 are available). Page size is saved when storage is available and encoded with page number in the URL. Changes to search, sort, category or facets reset to page one. The last page is clamped after results change. Catalogue metadata remains available for complete filtering; unshown product images are not inserted in the document. The first four images render eagerly; later images use lazy loading. Remote supplier image performance depends on its source.

Account notifications, payment release and supplier stock reservation behavior are unchanged.
