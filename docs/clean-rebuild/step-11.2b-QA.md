# Step 11.2B — Core Business Positioning

VoltTech should read as a PC hardware, gaming and creator-tech specialist, not a
repair shop with extra services.

Visible pillars:
- Custom gaming PCs / PC Builder
- Components, peripherals and upgrades
- Stream Support: OBS, Streamlabs, encoder/network, audio/capture and creator-PC performance
- Repairs, diagnostics and optimisation

Stream Support becomes a first-class navigation item and receives a dedicated
homepage feature. The existing specialist page is strengthened, not replaced.

Safety:
- staging only
- no commerce flag changes
- no supplier/stock claims
- no Supabase/backend changes
- no pricing changes
- full regression required
