// FAQ

Common questions

Will a clean install erase my files?

A clean installation can erase data depending on the method used. Important data should be backed up before the installation begins.

Do you include a Windows licence?

A Windows licence is separate unless specifically quoted. Existing activation may reactivate automatically when the device already has a valid digital licence.

Should I reinstall Windows to fix a slow PC?

Not automatically. A slow PC can be caused by storage, thermals, startup load or hardware limitations, so diagnosis is usually the better first step.
