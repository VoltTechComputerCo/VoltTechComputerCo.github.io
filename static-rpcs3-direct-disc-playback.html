RPCS3 Can Now Play PS3 Games Straight From the Disc

With a compatible Blu-ray drive, original PS3 discs can now be launched without first dumping the entire game to storage.

7 September 2026 · STATIC

Physical PlayStation 3 games just became much easier to use on a modern computer. The RPCS3 team says its open-source emulator can now boot games directly from a compatible Blu-ray disc drive, removing the old requirement to create a full game dump before playing.

It sounds like a small quality-of-life change. For collectors, preservation and anyone testing an old physical library, it is much bigger.

From “dump it first” to disc-in, game-on

The new workflow lets RPCS3 access a legally owned PS3 disc from supported optical hardware. There are caveats: not every Blu-ray drive can read PS3 media, and users still need the appropriate disc decryption key. This is not a bypass for Sony's content protection.

Why direct playback matters

A PS3 Blu-ray can consume tens of gigabytes when dumped. Multiply that by a shelf of games and local storage disappears quickly. Direct playback means a collector can test or play compatible discs without permanently duplicating the whole library onto an SSD.

The preservation angle matters even more. Physical media is independent of an account server or storefront. RPCS3's own announcement emphasizes playing games released as far back as 20 years ago without depending on servers.

STATIC signal: Mature emulation is increasingly making old physical libraries behave like they did on original hardware — while running on computers that may outlive that hardware by decades.

A feature users were already asking for

A March 2026 RPCS3 GitHub request described almost exactly this experience: mount a PS3 disc and play without first producing a traditional dump. By August, users were already reporting disc-drive-specific behaviour. The project is now publicly presenting direct playback as a usable workflow across its supported desktop platforms.

There are still limits

This does not make every USB Blu-ray drive compatible. Check RPCS3's current documentation before buying hardware specifically for the feature. Digital PS3 games and DLC remain a different workflow.

RPCS3 is an emulator, not a source of copyrighted games or keys. The straightforward use case is your own physical software and the data needed to use it. Within that boundary, direct-disc playback is exactly the kind of unglamorous feature that makes preservation software substantially better.
