# VoltTech Website Photography — upload pack

All 10 files are optimized .webp versions of your supplied VoltTech marketing images.
DO NOT rename these files. Their names are used by the website code.

## Upload to GitHub
1. Open the prepared draft pull request: https://github.com/VoltTechComputerCo/VoltTechComputerCo.github.io/pull/52
2. Select branch: feature/volttech-original-photography-20261103 and open assets/photography
3. Place all 10 WEBP files into **assets/photography/** on that branch.
   (Using Git locally: extract this ZIP into the repository root, then git add,
   git commit and git push the branch. Do not upload the ZIP itself.)
4. Open the draft PR for the branch, preview the homepage and these service pages:
   - index.html
   - pc-repair-pretoria.html
   - pc-upgrades-pretoria.html
   - pc-performance-optimisation.html
5. Only merge the PR after image paths and mobile layouts are verified.

The branch already contains:
- assets/js/volttech-photography.js
- assets/css/volttech-photography.css
- four HTML pages that load those assets

Safety: until all WEBP images are uploaded, the website code falls back
to current images, so there are no broken image placeholders.
Main/live site has not been changed yet.
Original marketing PNG images are not included in this deployment ZIP.

Image assets are for service/marketing pages. Product listings should continue
to use exact product/supplier images.
